# freelancehunt-alerts

Кожні 5 хвилин GitHub Actions перевіряє нові проєкти на Freelancehunt і Freelance.ua
(сайти, контекстна реклама / Google Ads, реклама в соцмережах / Meta Ads, автоматизація)
і надсилає їх у Telegram-групу.

## Налаштування
У Settings → Secrets and variables → Actions додайте:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Локальна перевірка без відправки: `npm run dry`.

## Автоматизація на Freelancehunt
Окремої категорії «Автоматизація» там немає, тому `scripts/check.mjs` збирає її двома способами:
- повністю беруться категорії: «AI та машинне навчання» (175), «Автоматизація управління підприємством» (ERP, 189), «AI-обробка текстів» (AI Content Creation, 197) і «Розробка ботів» (180);
- суміжні категорії (парсинг даних, CRM, AI-консалтинг, Python, JS/TS, консалтинг)
  беруться лише коли в назві чи описі є слова про автоматизацію: автоматизація, automation,
  n8n, Zapier, Make, Pabbly, workflow, парсинг, інтеграція.

Такі повідомлення мають позначку «🤖 Автоматизація». Для них окремий файл стану
`state/freelancehunt-auto.json`: на першому запуску наявні проєкти лише запам'ятовуються без сповіщень.
Списки категорій і слів змінюються на початку блоку «Автоматизація» в `scripts/check.mjs`.
(На Freelance.ua автоматизація вже входила в ключові слова.)
